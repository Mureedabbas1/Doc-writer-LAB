Practical guide

Flatten PDF Forms: complete guide

Flattening a PDF form turns interactive fields into a more fixed page appearance. This can help preserve completed fields when a document is viewed or printed in different PDF apps.

When should you use this tool?

It is useful for final copies of forms and submissions where recipients mainly need to view or print completed information. Flattening may remove interactive editing.

How to use it

Select a PDF containing supported form fields, run the flattening tool and save the result. Reopen the file to confirm values, checkboxes and layout.

Tips for better results

Keep an editable copy before flattening. Flattening is not the same as encryption, a digital signature or secure redaction.

Frequently asked questions

Why might a form not work? The PDF must contain supported interactive fields. Can flattened fields remain interactive? Usually not, so retain the original.
