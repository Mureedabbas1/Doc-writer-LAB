How to Split PDF Pages into Separate Files

Splitting helps when you need to share only a chapter, send one receipt, or separate a large document into smaller parts.

Explore free tools →

Choose the right split method

If you need a continuous section, extract a page range into a new PDF. If every page should become its own file, use the split-to-pages option. These workflows produce different results, so choose before uploading your file to the tool.

Enter page numbers carefully

PDF page labels printed on a document can differ from the file’s actual page positions. For example, a cover page may be counted as page 1 by the PDF viewer even if the printed numbering begins later. Preview the document and use the page positions expected by the tool.

Download and check

After processing, open the output and confirm that the first and last pages are correct. When many files are generated, use the ZIP download if available and check that the archive contains the expected pages.

If splitting fails

Make sure the file is a valid PDF, not a renamed image or Word document. Try a smaller file if the browser runs out of memory. Password-protected or damaged PDFs may need to be opened or repaired first.

Frequently asked questions

Can I extract non-consecutive pages?

Use a page-selection field that accepts comma-separated pages or ranges, if offered by the tool.

Does splitting delete pages from my original?

No. The tool creates new output files; your source remains unchanged.
