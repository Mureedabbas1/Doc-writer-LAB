About Doc Writer Lab

Doc Writer Lab is a set of free tools for everyday document jobs. Merge, split, rotate and compress PDF files, turn photos into a PDF, count words, change text case and run quick calculations without installing anything.

Doc Writer Lab is a browser-based online service, not a downloadable desktop software product. You use its tools directly in your browser; files downloaded after processing are your PDF or document outputs, not software installers. The website does not distribute a desktop application, installer, browser extension or plug-in.

The files you pick for supported local-processing tools are processed on your own device and are not sent to our file-processing servers.

The site is supported by advertising, which lets us keep every tool free.
