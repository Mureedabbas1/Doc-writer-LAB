How to merge PDF files without losing quality

Merging combines pages from supported PDFs into one document. It normally preserves the source page content rather than recompressing every image, but the result can still vary with file structure, annotations, forms, bookmarks and the processing library. Arrange files in the intended order, then open the result and check page count, links, forms and page appearance before deleting any originals.

How to make a PDF smaller for email

Many email services limit attachments to about 25 MB. Scanned PDFs are usually the biggest, because every page is a large image. Compressing re-saves those images at a lower quality, which can cut the size a lot. Start with medium compression and check that the text is still easy to read.

Turn photos into a PDF in three steps

A PDF is easier to share than a folder of pictures. Pick your JPG or PNG files, arrange them in reading order and create the document. For scans of paperwork, take photos in good light and hold the phone parallel to the page so the edges stay straight.

A practical guide to preparing, editing and sharing documents

Doc Writer Lab is built for specific document jobs rather than replacing a full desktop publishing or PDF editing suite. The safest workflow is to decide what needs changing, use the smallest suitable operation, and inspect the exported file before sending it.

1. Combine or separate information

Use Merge PDF when several related documents should become one file, such as a report with its appendices. Decide the page order first and check the first, middle and final pages after merging. Use Split PDF when a large document needs to become separate files, and use Extract Pages when only selected pages are required. Removing pages is different from extracting them: keep a copy of the original before either operation.

Merge PDF · Split PDF · Extract pages · Remove pages

2. Improve page layout and navigation

Scanned documents may arrive sideways or in an inconsistent order. Rotate pages to make them readable, reorder them to match the intended sequence, and add page numbers when readers need to refer to particular sections. Page numbers are visual labels; they do not repair missing pages or prove that a document is complete.

Rotate pages · Reorder pages · Add page numbers

3. Convert files with the right expectations

PDF-to-image conversion is useful when a page needs to be placed in a presentation or shared as a picture. Image-to-PDF conversion is useful for combining photographed receipts or paper notes into one document. PDF-to-text works best when the PDF already contains selectable text; a scan made from photographs generally needs OCR, which this tool does not provide.

PDF to JPG · JPG to PDF · PDF to text

4. Understand compression before using it

There is always a trade-off between file size and fidelity when page images are reduced. The current Doc Writer Lab compression workflow rasterises pages, so text may no longer be selectable or searchable. Do not use it when searchable text, accessible reading order, vector diagrams or form fields must be preserved. Compare the result with the original at normal size and high zoom.

Compress PDF · Read the compression guide

5. Treat signatures, forms and redaction carefully

A typed or drawn signature image is not the same as a certificate-backed digital signature. Flattening supported form fields can make their displayed values less editable, but it is not encryption and does not securely remove hidden information. Cropping a page is also not secure redaction. Use a dedicated redaction process when confidential text must be permanently removed, and follow the receiving organisation's requirements.

Add a visible signature · Flatten supported forms · Crop PDF pages

6. Create QR codes that people can actually use

Choose the QR format that matches the action: a website URL for a landing page, Wi-Fi for network access, vCard for contact details, or a social profile for a public account. Keep enough contrast around the code, avoid making it too small, and scan-test the downloaded image with more than one phone before printing. Check payment or bank payloads with the relevant provider; a generated code is not proof that a payment destination is valid.

How to choose the right PDF operation

Start with the outcome, not the tool name. If the pages are correct but in the wrong sequence, reorder them rather than converting the document. If you need only a few pages, extract those pages instead of sharing the complete file. If the file is too large, first check whether unnecessary pages or oversized images are responsible. Compression is not automatically the best first step.

  • Need one combined document? Merge the files, then confirm page order and total page count.
  • Need a smaller section? Extract a page range and open the new file to confirm the selected pages.
  • Need to share a page as a picture? Convert to JPG, then check that small text remains readable at the intended display size.
  • Need searchable text from a paper scan? Use OCR software designed for scanned documents; ordinary text extraction cannot recognise text that exists only as pixels.
  • Need to hide confidential information? Use a dedicated secure redaction tool and verify that the information cannot be selected, copied or recovered.

A quality check before you share

Open the downloaded result in a PDF reader rather than relying only on the browser's success message. Check the page count, page sequence, orientation, small print, tables, links, annotations and form values that matter to your task. Try selecting text if searchability is important. Confirm the output filename and file size, and keep the untouched original until the recipient has accepted the new copy.

Large documents can use substantial memory in a browser, especially on older phones or computers. If a task fails, close unused tabs, try a smaller batch and make sure the browser is up to date.
