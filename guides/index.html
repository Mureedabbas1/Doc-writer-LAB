Choose the right PDF workflow

Start with the result you need. Combining documents calls for a merge tool; extracting a few pages is different from splitting every page into separate files. Converting pages to images is useful for sharing or presentations, while extracting text works only when the PDF contains selectable text.

Guides for common tasks

Use our walkthroughs to merge PDFs, split page ranges, convert PDFs and images, add a visible signature, remove unwanted pages, extract text, understand compression, and protect your privacy while working with documents.

Check your output

Always open the downloaded file before sending it. Confirm page order, orientation, readability, file size and any signature or form fields that matter. Keep the original until you know the result is correct.

Are all PDF tasks possible in a browser?

Many common tasks are, but OCR, password recovery, advanced editing and verified digital signatures may require specialised software.
