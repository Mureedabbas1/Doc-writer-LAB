Prepare a PDF for Printing: Page Order, Rotation and Cropping

Remove, reorder, rotate and crop PDF pages in a sensible order before printing, with worked examples and tool limits.

Explore free tools →

Fix the file before you print it

Printing exposes every small flaw in a PDF. A scanned page that sits sideways wastes a sheet. Pages in the wrong order mean a stack to re-sort by hand. A wide white border on a scan shrinks the content to fit the paper, so the text prints small. Most of these are quicker to fix in the file than on paper, and none of them needs desktop software.

This guide covers three jobs in a sensible order: removing what you do not need, putting pages in order and turning them the right way up, and trimming margins. It uses the Remove PDF Pages, Reorder PDF Pages, Rotate PDF and Crop PDF tools, and it is explicit about what each does so that you are not surprised by the output.

How these tools work with your file

These tools open the PDF inside your browser, change the page structure and give you a new file to save. Your original is not modified, so you can always go back to it. Each run creates a separate download, which means that a multi-step job is a chain: you finish one tool, then load its output into the next. Name the files clearly as you go so you do not print an intermediate copy.

The tools change how pages are arranged and displayed. They do not redraw the page content, so text and images are not recompressed and quality is not reduced by any of the steps in this guide.

Recommended order of work

  1. Remove pages you will not print. Blank scan backs, cover sheets, and a duplicate page all make later steps harder. After removal, page numbers shift, so work out your page order only once the unwanted pages are gone.
  2. Reorder what remains.
  3. Rotate pages that are sideways.
  4. Crop margins last, after you can see the final page order and orientation.
  5. Open the result and look at every page before sending it to a printer.

Removing first matters because the reorder tool needs a complete list of the pages in the file, so a clean file means a shorter, simpler list.

Removing pages first

Open Remove PDF Pages, choose your file and enter the pages to delete as numbers, such as 2 or 2,5 or a span like 4-6. Scroll through the PDF in your viewer first and note the page numbers, counting from 1 at the front of the file. The number printed on a page, such as a roman numeral or a page 1 that is really the third sheet, may not match its position in the file. The tools use the position in the file.

If you want to keep only a few pages rather than delete many, Extract PDF Pages is quicker, because you list the pages to keep.

Putting pages in order

How the page sequence works

In Reorder PDF Pages you type the new order as a comma-separated list. The first number is the original page that should come first, and so on. For a three-page file, entering 3,1,2 puts the old page 3 first, then the old page 1, then the old page 2.

The tool is strict, and that protects you from mistakes. You must list every page, and each exactly once. For a 10-page file you need ten numbers between 1 and 10 with no repeats. If you leave one out or repeat one you get an error message rather than a damaged file. One consequence is that you cannot duplicate a page with this tool, and you cannot drop one either. Use the removal tool for dropping.

A worked example

You scanned a six-page contract and the last two sheets went through the scanner first. So the file starts with the last two sheets, followed by the first four. The correct start of the document is now on file page 3, and the sequence you need is pages 3, 4, 5 and 6 first, then 1 and 2 at the end, so you would enter 3,4,5,6,1,2. Open the result and check that the page that should start the document is first.

Two-sided scans

If you scanned the fronts of a stack and then the backs, the file alternates in the wrong way: all fronts, then all backs. For a file of 8 pages with fronts as 1 to 4 and backs as 5 to 8, the order you want is 1,5,2,6,3,7,4,8. Backs from a feeder are often in reverse order too, in which case it becomes 1,8,2,7,3,6,4,5. Look at your own file to see which applies, and test the first few pages before trusting the whole sequence.

Turning pages the right way up

Open Rotate PDF and choose 90 degrees clockwise, 180 degrees, or 270 degrees, which is 90 counter-clockwise. If you leave the pages box empty, every page is turned. To turn only some, type page numbers and spans such as 2,4-6.

Rotation adds to whatever turn a page already has, so a page already marked as turned 90 and rotated by another 90 ends up at 180. It is a display instruction stored in the file and the content is not redrawn, so quality is unaffected. A few things to bear in mind:

  • Check which way is up before choosing the angle. If a page is lying on its right side, you need 90 clockwise to bring it upright.
  • Landscape pages inside a portrait document are not a fault. Rotate them only if the text reads sideways when you look at the screen.
  • Rotation fixes how the page is shown. It does not fix a scan where the text itself is crooked by a few degrees. That needs a rescan or specialist software.

Cropping margins

Crop PDF trims the same percentage from all four edges of every page. You enter a number from 0 to 35. The percentage is applied to each page dimension separately, so five percent off a tall page removes slightly more from the top and bottom than from the sides in absolute terms.

It is a blunt instrument, and it helps to know what it cannot do:

  • You cannot set different margins on different sides, so it will not remove a wide binding edge on one side only.
  • It applies to every page. If some pages have content near the edge, a crop that suits the others could cut it off. Start small, such as 3 to 5 percent, and check the pages that have the most content near the edges.
  • It changes the visible page area. The content outside the crop is still stored in the file, so do not rely on cropping to hide anything private. For redaction you need a different tool.
  • Printing software may scale the cropped page up to fit the paper. That is usually what you want, because it makes the text larger, but it can change the printed size of diagrams that need to be to scale.

Before you press print

  1. Open the final file in a viewer and scroll through every page, not just the first.
  2. Check the first and last page of each section for order mistakes.
  3. Look at the edges for text clipped by a crop.
  4. In the print dialog, choose the right paper size and a scaling option. Fit to page and actual size give different results.
  5. Print a single test page, or a short range, before printing the whole job.
  6. For long documents you need numbered pages, use Add Page Numbers after the order is final, so the numbers match the sequence.

Honest limits

  • These tools handle ordinary, unlocked PDFs. A file that is password-protected or heavily restricted may not open.
  • Very large files depend on your device. A phone may struggle where a computer would not.
  • They do not repair damaged PDFs, deskew crooked scans or run OCR on scanned pages.
  • Each tool produces a new file, so a multi-step job needs several downloads. Keep track of which is current.

Frequently asked questions

Does rotating or reordering reduce quality?

No. Both change structure and display only, so the page content is not recompressed. That is different from compression, which does change the content.

Why does the reorder tool reject my list?

It needs every page number exactly once. Count the pages in your file and make sure your list has that many unique numbers.

Can I rotate just one page?

Yes. Type that page number in the pages box and leave the rest alone.

Is my file uploaded?

The tools process the file in your browser rather than sending it to a PDF server. See the PDF privacy guide for what that does and does not protect.
