QR code basics

A QR code is a square grid of dark and light modules that stores a short piece of data: usually a web address, but also plain text, a phone number or a contact card. A phone camera finds the three large squares in the corners, works out the orientation and grid size, and then reads the pattern back into characters. Because the pattern includes error-correction data, a code can still scan when part of it is dirty or scratched. The generators on this site create the code inside your browser and let you download it as a PNG image.

Every code has limits. The more data you store, the more modules are needed, and the smaller each one becomes at a given print size. A short link therefore gives a bolder, more reliable square than a long paragraph. For that reason the best codes carry a compact address and leave the details to the page it opens.

Static versus dynamic codes

There are two kinds of QR code. A static code holds the data itself. Once it is printed, the content cannot be changed, but it also keeps working forever without depending on any company or subscription, and nothing about your scans passes through a third party. A dynamic code holds a short redirect address belonging to a service, which can be pointed at a new destination later and usually counts scans, but stops working if the account lapses.

Every generator on this site makes static codes. That means no scan statistics and no edits after printing. If you need to change the destination later, point the code at a page you control and edit that page, or generate and print a new code. Always check the finished image before it goes to print.

How to choose a type

Start with what you want a scanner to do. If the answer is open a page, you only need the website type or one of the platform types below it. If you want an action such as a call, an email or a saved contact, pick from the contact group, because those open the phone dialler, mail app or address book directly. If the audience needs a file, host the file online first and use the matching file type. For selling, the business group offers menus, coupons, payments and tickets.

When two types seem equal, choose the more specific one. A YouTube code and a website code both store a link, but the specific page explains the details of that platform. Whichever you select, read the guide at the bottom of that page about the encoded format and about privacy.

Printing and scanning checklist

  • Contrast: use dark modules on a light background. Light codes on dark backgrounds fail with many scanners.
  • Quiet zone: leave a blank margin of roughly four modules around the code.
  • Size: a code about 2 cm wide scans at close range, while a poster seen from several metres needs 10 cm or more.
  • Test: scan the final printed version, not only the preview, on both an iPhone and an Android phone.
  • Surface: avoid curves, folds and glossy finishes that reflect light.
  • Fallback: print a short readable address next to the code for people who cannot scan.

Privacy and safety

Anything stored in a code can be read by anyone who scans it or photographs it, so treat the image as public. Never encode passwords you reuse, card numbers or private documents. Wi-Fi, payment, bank and contact codes carry the most sensitive details, and each of those pages has its own advice. Your data is turned into an image in your browser on this site and is not sent to us. As a scanner, check where a link leads before entering any information, and be wary of stickers placed over other codes on public posters.

Frequently asked questions

Are these codes free to use commercially?

Yes. The image you download is yours to print on products, menus and signs. Check that the content you encode, such as a trademark or a file, is yours to share.

Do the codes expire?

The image never expires, because it is static. It will only stop being useful if the page or file it points to is removed.

Can I add a logo or colours?

The generators produce a plain dark-on-white code and do not add logos. Plain codes are also the most reliable to scan.
