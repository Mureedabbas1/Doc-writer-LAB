PDF Tools: Frequently Asked Questions

Clear answers about using Doc Writer Lab's browser-based document tools, checking results and understanding their limitations.

Is Doc Writer Lab desktop software?

No. Doc Writer Lab is an online service used directly in your web browser. It does not distribute a desktop application, software installer, browser extension or plug-in. Files downloaded after using a tool are your resulting PDF or document outputs, not software to install.

Do I need to install an app or create an account?

No desktop app is required. Open the website in a supported, up-to-date browser. The available tools are designed to be used without an account unless a page explicitly states otherwise.

Are my files uploaded to Doc Writer Lab?

Supported PDF tools are designed to process selected files in your browser on your device rather than upload them to a Doc Writer Lab file-processing server. Some pages may load third-party scripts, fonts or other resources. Read the Privacy Policy for more detail, and avoid using shared devices for sensitive files.

Will every tool work with every PDF?

No. Compatibility depends on the PDF, browser and tool. For example, flattening requires supported interactive form fields, while text extraction may not work well on scanned pages without OCR. If a tool reports that a file is unsupported, try a different file or a specialised application.

Will compression always make a PDF smaller?

Not necessarily. Results depend on the file's contents and how it was compressed before. Compare the new file size and check small text, images and text selection against the original before sharing the result.

Is flattening the same as secure redaction or encryption?

No. Flattening changes how supported form fields appear in the document. It is not encryption, secure redaction or tamper-proof evidence. Keep an original copy, and use a purpose-built secure redaction tool when confidential information must be permanently removed.

How do I check the downloaded result?

Open the output file before relying on it. Check page order, orientation, readability, form values and file size as relevant. Keep the original until you are satisfied the result is correct.

Where can I read the policies?

Read our Terms and Conditions and Privacy Policy for information about permitted use, file handling, third-party resources and service limitations.
