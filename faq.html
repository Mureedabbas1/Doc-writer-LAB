Frequently Asked Questions

Quick answers about Doc Writer Lab and its browser-based document tools.

Is this desktop software?

No. Doc Writer Lab is an online service that you use directly in your web browser. It does not distribute a desktop application, software installer, browser extension or plug-in. When a tool finishes, you may download the resulting PDF or document; that is your output file, not software to install.

Are downloaded files software installers?

No. Files downloaded from the tools are the documents or results you asked the tool to create. They are not software installers or desktop applications.

Do I need to install anything?

No desktop application is required. Open the website in a supported, up-to-date browser and use the available tools there.

Are my files uploaded?

Supported PDF tools are designed to process selected files in your browser on your device. The website does not intentionally upload selected documents to a Doc Writer Lab file-processing server. Some features may use third-party resources; read the Privacy Policy for details.

Where can I read the terms?

See our Terms and Conditions and Privacy Policy.
