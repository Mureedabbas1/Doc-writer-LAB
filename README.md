# Doc Writer Lab

Doc Writer Lab is a browser-based document utility website published with GitHub Pages.

## Live website
https://mureedabbas1.github.io/Doc-writer-LAB/

## Tools included
PDF tools: Merge, Split, Rotate, Remove Pages, Add Page Numbers, PDF to JPG, JPG to PDF, Compress, Extract Pages, Reorder Pages, Watermark, Crop, PDF to Text, Sign, Add Text, and Flatten Supported Forms.

Text tools and calculators: Word Counter, Case Converter, Percentage Calculator, and Age Calculator.

Total: 20 tools.

## Privacy and limitations
PDF workflows process selected files in the browser; this repository does not provide a PDF upload server. Third-party CDN scripts and Google Fonts may be loaded. Compression rasterizes pages and may reduce text searchability. Cropping is visual only and is not secure redaction. Typed signatures are not verified digital signatures. PDF-to-text does not perform OCR on scanned image-only pages.
