# Doc Writer Lab

Doc Writer Lab is a browser-based collection of free PDF, document, text and QR-code utilities, published with GitHub Pages.

## Live website

https://docwriterlab.site/

## Tools included

### PDF and document tools
Merge PDF, Split PDF, Rotate PDF, Remove Pages, Add Page Numbers, PDF to JPG, JPG to PDF, Compress PDF, Extract PDF Pages, Reorder PDF Pages, Add PDF Watermark, Crop PDF, PDF to Text, Sign PDF, Add Text to PDF, and Flatten Supported PDF Forms.

### Text tools and calculators
Word Counter, Case Converter, Percentage Calculator, Age Calculator, Character Counter, Sentence Counter, Line Counter, Text Cleaner, Duplicate Line Remover, Line Sorter, Text Reverser, Find and Replace, Slug Generator, and Lorem Ipsum Generator.

### QR code generators
30 QR tools: Website URL, Text, Email, Phone, WhatsApp, SMS, vCard, Business Card, Google Maps, Wi-Fi, Facebook, Instagram, TikTok, YouTube, LinkedIn, Snapchat, Telegram, Social Links, PDF, Image, Video, Audio, Google Drive, Payment Link, Bank Account Payload, Event/Ticket, Restaurant Menu, Product, App Download, and Coupon.

The homepage currently lists 30 PDF/document/text utilities and a separate set of 30 QR generators. See the live homepage and QR tools page for the current inventory.

## Privacy and limitations

PDF workflows are designed to process selected files in the browser on the user's device; this repository does not provide a PDF upload server. QR payloads are generated in the browser and are not intentionally sent to a Doc Writer Lab QR storage server. Third-party CDN scripts, Google Fonts, Google Analytics 4 and Google AdSense may be loaded; see the live Privacy Policy for details.

Compression may rasterize PDF pages and reduce text searchability. Cropping is visual only and is not secure redaction. Typed signatures are not verified digital signatures. PDF-to-text does not perform OCR on scanned image-only pages. QR payment and bank-transfer payloads are not guaranteed to be compatible with every bank or payment provider; verify with the provider and test every QR before use.
