Large PDFs can be difficult to email or upload. This tool attempts to reduce file size where its supported processing can do so; the reduction depends on the contents of the file.

How to use Compress PDF

  1. Choose the PDF to process.
  2. Run compression with the available settings.
  3. Compare the output size and inspect readability.

When processing finishes, save the output and open it once to confirm it looks right.

Privacy and file handling

Not every PDF can be made significantly smaller. Keep the original and check the output before sending it. Keep a copy of your original file until you have checked the result. Avoid using public computers for sensitive documents.
